# ネジ抜きパズル 3D

ネジを外して建物を解体していく 3D パズル。全50ステージ（小屋・家・家電・乗り物・大型建築・城）。

**遊ぶ → https://m1gawar1.github.io/screw-puzzle-3d/**

- 同じ色のトレイにしかネジを入れられない。3本そろうとトレイが空く
- 手前の部品が邪魔なネジは、先にその部品を外す必要がある。まだ外せないネジは暗く表示される（押すと原因の部品が光る）
- ドラッグで回転、ピンチ／ホイールでズーム
- 難易度は「やさしい／ふつう／むずかしい／エキスパート」。どの難易度でも必ず解ける配色になっている

## このリポジトリについて

`index.html` 1ファイルだけで動く（three.js r128・モデル定義・フォントをすべて埋め込み済み、外部読み込みゼロ）。
ダウンロードしてローカルで開いてもそのまま遊べる。

生成元は別管理の開発用ファイル（`screw-puzzle-3d.html` ＋ `kit-models.js`）で、ここにあるのはビルド済みの成果物。

## おまけ：雪原サバイバル・ラン（`whiteout-run.html`）

雪原を走ってゲートで仲間を増やし、最後の氷の怪物を倒す、広告でよく見るタイプのミニゲーム。
ブラウザで `whiteout-run.html` を開くだけで遊べる（スマホはドラッグ、PC は ←→ / A D キー）。
特定のゲームとは無関係の、遊び方だけ似せたオリジナル作品。

## おまけ2：雪原の町づくり（`snow-town.html`）

木を切って丸太、クマを倒して肉、岩を掘って石、狼から毛皮を集め、お店で売ったお金と素材で町を発展させる経営アクションゲーム。
ドラッグ（PCは WASD / 矢印キー）で移動、木・岩・敵には近づくだけで自動攻撃。
ローポリ3Dで表示（three.js r128 を埋め込み）。右下のボタンで軽い2D表示に切り替えられ、3Dが使えない端末では自動で2Dになる。

- エリア：森 → 鉱山（石）→ 氷原（狼・毛皮）→ 白熊の巣（ボス）。お金を払って開拓する
- 建物：かまど・肉焼き台・家×6（家賃）・木こり／狩人／鉱夫小屋・鍛冶屋・毛皮屋・見張り塔・大かまど（クリア）
- 何度でも強化（強化広場）：斧・カゴ・ブーツ・防寒着・看板（値上げ）・倉庫拡張、働き手の雇用
- 倉庫：素材を預ける／取り出す。運搬係が丸太・石・毛皮を自動で運び込む
- 金庫：集金係が家賃や売上のコインを集めて保管。罠師が狼を狩って毛皮を集める
- 村の壁と3つの門、矢倉・見張り塔から矢で迎撃。定期的に狼の群れが襲撃してくる
- ミッション、落とし物を拾ってくる犬、肉と薪でシチューを作る料理屋
- 釣り：氷原の穴の近くで自動で魚が釣れる。漁師小屋で漁師が釣って市場へ運ぶ。魚は市場で売れて、料理屋の材料にもなる
- 白熊の巣：氷晶（青い結晶）が掘れる／白熊が落とす。交易所で氷晶とあまった石を買い取ってもらえる。氷晶の斧・氷の灯台・雪の城に使う
- 狩人・罠師・漁師の届け先は「半分ずつ／お店優先／倉庫優先」を倉庫横のマスで切り替えられる
- 白熊ハンター：氷晶を掘り、白熊を倒して素材を倉庫へ運ぶ
- 資材商：お金で丸太・石・毛皮・肉・魚・氷晶を買える
- 矢倉は最大8基。守りが固いほど襲撃の数と強さが増え、大狼（ボス）も出る。そのぶん報酬も増える
- 自警団：襲撃者と戦う。斧・氷晶の斧の強化で、自警団と働き手（木こり・鉱夫・狩人など）も強くなる
- 倉庫横の「売り払う」マスで、いらない荷物を半値で処分できる
- 終盤のお金の使い道：働き手の道具（足が速く・たくさん運ぶ）、町の格上げ（売値・家賃アップと称号）、王国へ献上（勲章）
- 右下の ⚙ から「引き継ぎコード」をコピー／復元できる（別の端末やブラウザで続きを遊べる）
- 初めて遊ぶときは、画面下の「案内」が最初の流れを教えてくれる
- 料理屋の材料は、倉庫に肉と丸太があれば運搬係が自動で補給する
- 効果音とBGM（Web Audio で合成）。右下のボタンで音のオン・オフ
- お金の大きな使い道：英雄の像（売値アップ）、大宴会（2分間 売値・家賃1.5倍）、温泉、雪の城
- 補給物資がときどき落ちてくる。ミニマップと発展度つき。進行はブラウザに自動保存
- 大かまどは中盤のゴール。そのあとは白熊の巣の東にある「氷河の洞窟」へ
  - 洞窟の中は暗く、たいまつの明かりの範囲だけ見える。金と宝石が掘れ、氷のコウモリと氷のゴーレムが出る
  - 洞窟の前の拠点：金細工屋（金・宝石を買い取る）、鉱山列車（トロッコが金を運んでくる）、金の像
  - 強化広場の「金と宝石」の列：たいまつ・宝石の斧・宝石の鎧・金の像・列車の強化・洞窟の灯り
- ボス：森の主・狼王・白熊の王・氷の大ゴーレム。倒すと強化の上限が上がる。攻撃の前に地面に赤い印が出るので、外へよける
- おまかせ（左下のボタン）
  - 強化係の小屋を建てると、ONにした強化を強化係が倉庫の素材と手持ちのお金で進めてくれる
  - あふれた素材を自動で半値で売る／倉庫の余りを運搬係がお店に並べる（それぞれON・OFFできる）
- 金と宝石も倉庫に入る。鉱山列車は倉庫まで直接運ぶ。倉庫の拡張でお店の棚も広がる
- 4体を倒すと「巨人の扉」が開けられる。奥の雪の巨人を倒すと本当のエンディング（クリア時間が出る）
